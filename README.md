# Cabin - AI CFO for Startup Founders

This is the foundational project scaffold for the Cabin SaaS landing page.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Lucide Icons

## Folder Structure
- `/app`: Next.js App Router pages and layouts.
- `/components/sections`: Landing page sections (Hero, Features, Pricing, etc.).
- `/components/ui`: Reusable shadcn/ui components.
- `/lib`: Utility functions (e.g., `utils.ts` for Tailwind classes).
- `/public`: Static assets like images and fonts.

## Design Tokens
- **Primary:** `#6C3BFF`
- **Background:** `#070B1B`
- **Card:** `#11152B`
- **Text:** `#FFFFFF`
- **Secondary Text:** `#B5B8C7`
